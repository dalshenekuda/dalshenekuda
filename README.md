# Arseniy Polyak

Senior Shopify Frontend Engineer - subscription commerce, Hydrogen, design systems.

I build the storefront layer for a Shopify Plus DTC brand across 17 country storefronts: product flows, cart/checkout with Selling Plans, and customer self-service. Outside day-to-day delivery, I maintain two open projects that show the same approach applied to headless commerce.

## Projects

**[CandyUI](https://github.com/dalshenekuda/CandyUI)** — React design system for headless Shopify storefronts (Hydrogen). Token-driven UI primitives, documented in Storybook, published to npm with automated Changesets releases and OIDC-verified provenance via GitHub Actions.
[npm](https://www.npmjs.com/package/@dalshenekuda/candy-ui) · [Storybook](https://main--6ab56ef1aed13efbc107d427.chromatic.com/)

**[CandyArea](https://github.com/dalshenekuda/CandyArea)** — Hydrogen storefront demo built on CandyUI, showing the design system in a real headless Shopify build.
